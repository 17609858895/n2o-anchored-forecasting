# Avedore data provenance

Analysis input: `../aved_raw.csv.gz` contains timestamps and value columns rounded to four decimals, with quality flags omitted. It is the input actually used by this study's analysis scripts.

`mendeley_v1_original.csv.gz` preserves the complete original V1 CSV, including quality flags and full precision. Its uncompressed SHA-256 is `d1cf007ddd79fb7924ac0e06612d3fb57a5c5027bc7cc24069eae06bc6e8bd07`.

Source: Hansen, Laura Debel, *Time Series Dataset for Modeling and Forecasting of N2O in Wastewater Treatment*, Mendeley Data V1, https://doi.org/10.17632/xmbxhscgpr.1. License: CC BY 4.0. The analysis extract is a modified representation of these source data; the complete source is preserved separately.
